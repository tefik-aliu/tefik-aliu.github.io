IMPLEMENTATION / SERVICE CONTRACT

app/main.py · L61–71Source ↗ 
    @app.get("/health")
    def health() -> dict[str, str]:
        return {"status": "ok", "service": "service-observability-lab"}

    @app.get("/ready")
    def readiness(db: Session = db_dependency) -> dict[str, str]:
        try:
            db.execute(text("SELECT 1"))
        except SQLAlchemyError as exc:
            raise HTTPException(status_code=503, detail="Database unavailable") from exc
        return {"status": "ready", "database": "connected"}

Readiness queries the database. Liveness checks the process. Inspect the implementation and the deployment probes together.
