Service Observability Lab

Retry an API request without creating a duplicate job.

A job-management API with a web interface to create and update jobs. Idempotency keys let repeated requests reuse the same result. Database checks, Prometheus metrics and optional OpenTelemetry tracing make the service inspectable. Compose configures PostgreSQL; Kubernetes manifests describe deployment.
