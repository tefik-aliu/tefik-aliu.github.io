01 / ARCHITECTURE

The request is only
part of the system.

The problem

An endpoint can return a successful response while the service remains difficult to diagnose. This project adds dependency checks, request metrics and trace instrumentation to a small job API.

The implementation

FastAPI handles a queued, running, completed or failed job lifecycle. PostgreSQL stores state in the Compose stack; Prometheus collects metrics, Grafana presents them, and an optional OpenTelemetry exporter sends traces to a collector.

02 / DESIGN DECISIONS

Operational behaviour
as an explicit contract.

An application factory

create_app() accepts a database URL. Tests can isolate persistence with SQLite while the container stack uses PostgreSQL.

Inspect implementation ↗

Health and readiness

/health identifies a responding process. /ready executes a database query. Kubernetes manifests bind them to separate liveness and readiness probes.

Inspect implementation ↗

Metrics with application context

Request counts and latency are exposed alongside jobs created and jobs by status, connecting HTTP behaviour to service state.

Inspect implementation ↗

Tracing behind configuration

OTLP export is enabled through an environment variable. Without an endpoint, the service runs without tracing infrastructure.

        return {"status": "ok", "service": "service-observability-lab"}

    @app.get("/ready")

        db.execute(text("SELECT 1"))

05 / RESULT & NEXT STEPS

Reproducible integration.
Documented boundaries.

The repository contains a runnable service, a local observability stack, tests and deployment assets. It demonstrates the integration of application behaviour and operational tooling.

The collector uses a debug exporter. Persistent trace storage, authentication, migrations, SLO alerting and a staged rollback pipeline remain extensions. Kubernetes manifests are deployment definitions; they do not establish a production operating history.

Implementation history +

The original integration notes record workflow setup, npm cache configuration, Ruff findings and Python import-path fixes. The commit and CI history remain available for inspection.
