01 / ARKITEKTUR

Anropet är bara
en del av systemet.

Problemet

Ett API kan svara korrekt samtidigt som tjänsten är svår att felsöka. Projektet kompletterar ett litet jobb-API med beroendekontroller, anropsmätvärden och spårning.

Implementationen

FastAPI hanterar jobb med status queued, running, completed eller failed. PostgreSQL lagrar tillstånd i Compose-stacken, Prometheus samlar mätvärden, Grafana visar dem och en valfri OpenTelemetry-exportör skickar spår till en collector.

    @app.get("/health")
    def health() -> dict[str, str]:
        return {"status": "ok", "service": "service-observability-lab"}

    @app.get("/ready")
    def readiness(db: Session = db_dependency) -> dict[str, str]:
        db.execute(text("SELECT 1"))
        return {"status": "ready", "database": "connected"}

05 / RESULTAT OCH NÄSTA STEG

Återskapbar integration.
Dokumenterade gränser.

Kodarkivet innehåller en körbar tjänst, en lokal observability-stack, tester och driftsättningsfiler. Det visar integrationen mellan applikationsbeteende och driftverktyg.

Collectorn använder en debug-exportör. Beständig spårlagring, autentisering, migreringar, SLO-larm och stegvis återställning återstår som utbyggnader. Kubernetes-manifest är driftsättningsdefinitioner, inte bevis på produktionsdrift.
