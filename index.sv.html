Service Observability Lab

Samma API-anrop igen, utan ett dubbelt jobb.

Ett API för jobbhantering med en webbsida för att skapa och uppdatera jobb. Idempotensnycklar gör att upprepade anrop återanvänder samma resultat. Databaskontroller, Prometheus-mätvärden och valbar OpenTelemetry-spårning gör tjänsten lättare att undersöka. Compose konfigurerar PostgreSQL; Kubernetes-manifest beskriver driftsättning.

FastAPI · PostgreSQL · Docker · Prometheus · OpenTelemetry
